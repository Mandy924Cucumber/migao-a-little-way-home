# 米糕出逃记 · A Little Way Home

一个可以直接游玩的 Godot 4 第三人称 3D 小游戏。主角是一只叫米糕的小猫，要悄悄离开奶奶的公寓，沿花园小路找到猫咪伙伴。

## 打开与运行

1. 用 Godot 4 打开本目录的 `project.godot`。
2. 按 **F6** 运行主场景，或按 **F5** 运行整个项目。
3. 点击「出发，去找伙伴」，或按 Enter。

已经在本机的 **Godot 4.7.2 / macOS / Intel OpenGL Compatibility** 上运行验证。首次打开会导入资源。场景在启动时由脚本生成，因此编辑器未运行时主场景只有一个根节点；运行后可以在「远程」场景树查看所有对象。

也可以双击项目里的 `开始游戏.command`。它会优先寻找已安装在 Downloads 或 Applications 的 Godot。

## 操作

| 按键 | 操作 |
|---|---|
| WASD / 方向键 | 相对于镜头移动 |
| 鼠标 | 第三人称环视 |
| 滚轮 | 调整镜头距离 |
| 空格 | 跳跃，可以跳上床、沙发和矮桌 |
| Shift | 奔跑，消耗体力；松开后恢复 |
| Ctrl | 慢走、压低身体 |
| E | 门、灯、纸箱、收音机、床、小碗、水龙头等互动 |
| Q | 喵叫，搜索时会暴露位置 |
| Esc | 暂停 / 继续，同时释放鼠标 |

## 游戏规则

- 公寓包括客厅、两个卧室、浴室、厨房和走廊。家具具有实体碰撞。
- 奶奶平时散步，不会因为看见你就抓你。
- 进入距离出口约 4 米的区域，并被奶奶看见，或被发现已经出门，会触发追赶。
- 墙壁、关闭的房门和高家具都能挡住视线。逃出视线 1.25 秒后进入搜索；约 5.5 秒没找到就恢复散步。
- 未被追赶中的奶奶直视时，可以按 E 躲进纸箱；再次按 E 出来。直接当着奶奶的面钻纸箱不会让追赶失效。
- 收音机或厨房水龙头能引开奶奶约 9 秒。打开大门，抓住机会奔向花园。
- 床需要自己跳上去，站在床上按 E 恢复体力；水碗也可以恢复体力。
- 在野外石板路尽头进入五只猫围成的区域即获胜；被抓可以重试，没有战斗或伤害表现。

## 项目结构

- `scenes/main.tscn`：启动场景。
- `scripts/game.gd`：游戏流程、输入、导航、互动和程序音效。
- `scripts/apartment.gd`：五房公寓、家具、花园、碰撞和静态网格合批。
- `scripts/cat_player.gd`：小猫运动、跳跃、奔跑和防穿墙镜头。
- `scripts/actor_body.gd`：角色实体碰撞、低台阶通行和安全落点检查。
- `scripts/grandma.gd`：巡逻、视线判断、追赶、搜索与分心。
- `scripts/art.gd`：原创小猫、奶奶及基础模型。
- `scripts/hud.gd`：中文菜单、地图、体力、提示与胜负界面。
- `shaders/wood.gdshader`：木纹材质。
- `tests/gameplay_test.gd`：自动化玩法验证。
- `tests/collision_test.gd`：模型尺寸、家具、门、角色、镜头和实际寻路的防穿模验证。
- `artifacts/`：引擎直接渲染的实机截图。

所有模型、材质和音效均随代码生成，无外部资源下载或联网依赖。画面采用温暖的几何卡通风格；这是一份完整可玩的首版，角色尚未使用专业骨骼动画或写实模型。

## 检查

```sh
godot --headless --path . --script tests/gameplay_test.gd
godot --headless --fixed-fps 60 --path . --script tests/collision_test.gd
```

检查内容包括房间和猫群、和平探索、出口警戒、真实墙壁与家具遮挡、关门和开门、搜索恢复、纸箱进出、声音吸引、所有房间的导航、实际跳上床、出口连通、胜利与被抓。

角色的碰撞范围覆盖完整模型，米糕和奶奶会互相阻挡。打开的门仍保留实体碰撞，门转动时会等待挡路的角色离开。床上被褥、沙发坐垫、桌腿、花盆、树干和灌木都有对应碰撞；角色可自动跨过地毯和石板路的小台阶。离开纸箱会回到进入时的位置，位置被占用时会等待。客卧衣柜和纸箱的位置留出了进门通道。
